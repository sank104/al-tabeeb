The Clinical Compass - static website (no build step, no server needed)

Open index.html in any browser.

index.html          page shell (sidebar, home, search view)
css/style.css       all styling (light/dark, responsive)
js/app.js           navigation, search, read-marks, Google buttons
js/data/index.js    index of all sections (used by the search box)
js/data/part-NN.js  content of each of the 16 parts (cards + full text)
